# 🧪 Инструкция по тестированию бота

## Проблема: "Бот не реагирует"

Если бот не отвечает на сообщения, следуйте этой инструкции.

## ✅ Шаг 1: Проверьте токен

```bash
python check_bot_info.py
```

Должна отобразиться информация о боте:
- Название: **Профориентация ЦОПП**
- Username: **@id3123232342_bot**
- ID: **100197997**

## ✅ Шаг 2: Остановите бота (если запущен)

Нажмите `Ctrl+C` в терминале где запущен `bot.py`

## ✅ Шаг 3: Проверьте обновления

```bash
python debug_updates.py
```

Это покажет, есть ли необработанные сообщения.

## ✅ Шаг 4: Запустите бота ЗАНОВО

```bash
python bot.py
```

Вы должны увидеть:
```
============================================================
🤖 БОТ ЗАПУЩЕН
============================================================
API: https://platform-api.max.ru
Токен: f9LHodD0cOJrQZ9iPZqM...
============================================================

⏳ Ожидание обновлений...
💡 Отправьте боту сообщение в MAX: https://max.ru/id3123232342_bot
```

## ✅ Шаг 5: Отправьте НОВОЕ сообщение

**ВАЖНО:** Старые сообщения уже обработаны! Нужно отправить НОВОЕ!

1. Откройте MAX мессенджер
2. Найдите бота: https://max.ru/id3123232342_bot
3. Напишите: **привет** или **/start**
4. Смотрите в терминал - бот должен отреагировать!

## 📊 Что должно произойти:

### В терминале бота:
```
📬 Получено обновлений: 1
📨 Сообщение от 123456: привет
```

### В MAX мессенджере:
Бот отправит приветственное сообщение с кнопкой "🚀 Начать тестирование"

## 🐛 Если бот всё равно не реагирует:

### Проверка 1: Один экземпляр бота
Убедитесь, что `bot.py` запущен только в ОДНОМ терминале!

```bash
# Windows: найти процессы Python
tasklist | findstr python
```

### Проверка 2: Правильный токен
Откройте `.env` файл и проверьте токен:
```
VK_BOT_TOKEN=f9LHodD0cOJrQZ9iPZqMom9zEZQbFEYafmllyRhsWVQZtXGghVYiSTQrOiijttQyZnxcLFcVMUp55X4JFWFE
```

### Проверка 3: API доступен
```bash
python test_api.py
```

Все пункты должны быть ✅

## 🎯 Тестирование функций бота:

После того как бот ответил на приветствие:

1. **Нажмите кнопку "Начать тестирование"**
   - Бот должен отправить первый вопрос

2. **Выберите вариант А или Б**
   - Бот должен отправить следующий вопрос

3. **Пройдите все 30 вопросов**
   - После 30-го вопроса бот покажет результаты

4. **Проверьте результаты**
   - Должны отобразиться баллы по критериям
   - Должен быть список рекомендуемых ПОО

## 📈 Проверка админ-панели:

1. Запустите админ-панель (в отдельном терминале):
```bash
python admin_panel.py
```

2. Откройте в браузере: http://localhost:5000

3. Проверьте разделы:
   - **Дашборд** - должна отобразиться статистика
   - **Вопросы** - 30 вопросов
   - **ПОО** - 33 учебных заведения
   - **Результаты** - результаты тестирования (после прохождения теста)
