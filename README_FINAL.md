# MAX Бот - Профориентационное тестирование

Бот для мессенджера MAX (VK) с профориентационным тестированием по методике Климова и веб-админ панелью.

## 📋 Возможности

### Бот MAX:
- ✅ Профориентационное тестирование (30 вопросов)
- ✅ Подсчет баллов по 5 критериям Климова
- ✅ Рекомендации учебных заведений на основе результатов
- ✅ Интерактивные кнопки для ответов
- ✅ Сохранение результатов в БД

### Веб админ-панель:
- ✅ Дашборд с общей статистикой
- ✅ Просмотр всех вопросов теста
- ✅ Список ПОО с критериями
- ✅ Результаты тестирования пользователей
- ✅ Графики и аналитика

## 🔧 Как работает бот

### Процесс тестирования:

1. **Пользователь запускает бота** → Отправляет `/start` или "Привет"
2. **Бот отправляет приветствие** с кнопкой "Начать тестирование"
3. **Пользователь нажимает кнопку** → Начинается тест
4. **Бот задает 30 вопросов** по очереди
5. **Пользователь выбирает вариант** А или Б
6. **Бот считает баллы** по 5 критериям:
   - Человек-человек
   - Человек-природа
   - Человек-техника
   - Человек-знаковые системы
   - Человек-художественный образ
7. **После 30 вопросов** бот показывает результаты
8. **Если критерий ≥ 5 баллов** → Показываются подходящие ПОО

### База данных:

**Таблицы:**
- `users` - пользователи бота
- `questions` - вопросы теста
- `educational_organizations` - ПОО
- `test_results` - результаты тестирования

## 📊 Критерии Климова

| Критерий | Описание |
|----------|----------|
| **Human** | Человек-человек (профессии, связанные с общением) |
| **Nature** | Человек-природа (работа с животными, растениями) |
| **Tech** | Человек-техника (технические профессии) |
| **Sign** | Человек-знаковые системы (работа с информацией, документами) |
| **Art** | Человек-художественный образ (творческие профессии) |

## ⚙️ API MAX

Бот использует официальное MAX Bot API:
- **Базовый URL:** `https://platform-api.max.ru`
- **Метод получения обновлений:** Long Polling (GET /updates)
- **Отправка сообщений:** POST /messages
- **Inline-клавиатура:** Кнопки с callback

Документация: `MAXAPI/apimax.txt`

## 🛠 Troubleshooting

### Бот не отвечает:
1. Проверьте токен в `.env`
2. Убедитесь, что бот запущен (`python bot.py`)
3. Проверьте интернет-соединение

### Админ-панель не открывается:
1. Убедитесь, что Flask запущен (`python admin_panel.py`)
2. Откройте http://localhost:5000 в браузере
3. Проверьте, свободен ли порт 5000

### База данных пустая:
Запустите `python load_data.py` для загрузки данных
